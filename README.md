# watch-diff 文件变更实时监控

一个基于 Python tkinter 的文件变更实时监控 GUI 工具。选择文件夹，实时监控文件变动，自动渲染 unified diff，并追溯是哪个进程修改了文件。

## 功能特性

- **实时监控** — 选择文件夹，自动扫描并轮询文件变动
- **Unified Diff** — 实时渲染行级 diff，增删高亮
- **进程溯源** — 利用 psutil 反查文件句柄，知道是哪个编辑器/工具改的
- **去重队列** — 短时间内多次保存只触发一次 diff
- **冷却机制** — 可配置冷却时间，避免频繁刷屏
- **可配置文件类型** — 自由选择监控哪些扩展名
- **文件过滤条** — 按文件切换显示/隐藏变更
- **可配置编辑器过滤** — 只显示指定进程的变更
- **归档打包** — 控制台内容达 10MB 阈值时自动 gzip 打包存档
- **多窗口支持** — 同时监控多个文件夹
- **历史记录** — 自动记住最近监控的文件夹

## 依赖

```bash
pip install psutil
```

> psutil 是可选依赖，不安装时仅不可用进程溯源功能，其余正常。

## 使用方式

```bash
# 启动 GUI，浏览选择文件夹
python watch_diff.py

# 直接指定文件夹启动
python watch_diff.py D:\\my_project
```

## 开发背景

最初是为了在使用 AI Agent 做项目时，能实时看到 Agent 到底改了哪些文件、改了什么内容。
